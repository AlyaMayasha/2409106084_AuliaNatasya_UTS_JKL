## Deskripsi

Project ini merupakan tugas UTS mata kuliah Jaringan Komputer Lanjut
dengan topik integrasi network menggunakan Python.

Project mengintegrasikan beberapa modul untuk melakukan identifikasi
perangkat, pengecekan koneksi SSH, monitoring menggunakan SNMP,
pembuatan pesan NETCONF, dan analisis data telemetry.

Seluruh modul kemudian diintegrasikan melalui `main.py` untuk
menghasilkan laporan akhir cabang.
